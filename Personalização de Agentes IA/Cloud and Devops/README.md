# Cloud and Devops

Esta pasta contém um prompt de personalização para configurar um agente de IA especializado em **arquitetura de nuvem (Cloud Computing) e práticas DevOps/SRE**. O prompt define o contexto do usuário (profissional atuante na arquitetura, gerenciamento e automação de infraestruturas em nuvem) e指示a IA a atuar como um arquiteto de soluções cloud sênior e engenheiro SRE principal.

## Descrição e Propósito
O objetivo deste prompt é adaptar o comportamento de um modelo de linguagem para atender às necessidades de profissionais de cloud e DevOps. Ele fornece:
- **Parte 1:** Informações sobre o usuário, incluindo seus pilares de atuação: provedores de nuvem (AWS, GCP, Azure), infraestrutura como código (Terraform, OpenTofu, CloudFormation, Ansible), conteinerização e orquestração (Docker, Kubernetes), CI/CD (GitHub Actions, GitLab CI, Jenkins), observabilidade e SRE (Prometheus, Grafana, Datadog, ELK), e cloud finops & segurança.
- **Parte 2:** Diretrizes de como a IA deve responder: agir como arquiteto de soluções cloud sênior e engenheiro SRE principal, ser extremamente técnico e objetivo, fornecer diagramas conceituais, códigos de IaC, comandos de terminal ou arquivos de configuração, aplicar melhores práticas de segurança, apresentar vantagens de resiliência e impacto de custo, sugerir alternativas serverless quando apropriado, e usar blocos de código com sintaxe correta e tabelas para mapear permissões ou estruturas de rede.

## Instruções de Uso
1. Abra o arquivo `Personalização de IA.txt`.
2. Copie todo o conteúdo do arquivo.
3. Cole o texto copiado na conversa com seu modelo de linguagem preferido (ChatGPT, Gemini, Claude, etc.).
4. A IA agora terá o contexto e as diretrizes para auxiliá-lo em desenhar sistemas escaláveis, seguros, tolerantes a falhas e otimizados financeiramente, bem como em automação de infraestrutura, pipelines CI/CD, observabilidade e otimização de custos.
5. Opcionalmente, você pode adaptar as seções para refletir seu foco específico dentro de cloud ou DevOps.
