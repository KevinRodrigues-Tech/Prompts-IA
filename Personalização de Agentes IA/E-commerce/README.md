# E-commerce

Esta pasta contém prompts de personalização para configurar agentes de IA especializados em **e-commerce, dropshipping e criação de lojas virtuais de alta conversão**. Dentro dela encontram-se um prompt geral de personalização e uma subpasta `Projetos` com um prompt específico para cadastro de produtos na plataforma Nuvemshop.

## Descrição e Propósito
Os prompts nesta área são destinados a adaptar o comportamento de modelos de linguagem (ChatGPT, Claude, Gemini, etc.) para atender às necessidades de empreendedores e profissionais de e-commerce, especialmente no modelo de dropshipping. Eles se dividem em duas especializações:

1. **Prompt Geral de Personalização para E-commerce/Dropshipping** (`Personalização de IA.txt`)  
   - **Parte 1:** Informações sobre o usuário, incluindo atuação como empreendedor de dropshipping, uso do chat como hub de criação, design e otimização de lojas virtuais de alta conversão, foco em construir marcas sólidas (Shopify/Yampi) com experiência de usuário impecável.  
   - **Pilares:** SEO para dropshipping (títulos magnéticos, URLs amigáveis, meta descrições focadas em CTR, pesquisa de palavras-chave); copywriting de conversão (frameworks AIDA, PAS, quebra de objeções, ofertas irresistíveis, gatilhos mentais de escassez e urgência); identidade de marca & branding (tom de voz, naming, proposta exclusiva de valor, posicionamento de mercado); UI/UX & design para e-commerce (estruturação de landing pages, wireframes de páginas de produto, paletas de cores estratégicas, briefings detalhados para criativos visuais); social media orgânico & vídeos (roteiros dinâmicos para Reels/TikTok, ideias de conteúdo para feed e stories).  
   - **Parte 2:** Diretrizes para que a IA aja como Diretor de Criação e Especialista em UX/UI focado em e-commerce de alta conversão; fornecer respostas práticas, visuais e prontas para implementação; quando solicitada descrição de produto, enviar estrutura completa de copy (título SEO, subtítulo, dor, solução, benefícios em bullet points, FAQ, meta descrição); adotar tom que equilibre profissionalismo de marca nativa digital (D2C) com técnicas agressivas de conversão do dropshipping; explicar motivo psicológico por trás de layouts ou designs (ex: prova social, posicionamento do botão de compra); organizar respostas usando tabelas, blocos de código e negritos.

2. **Prompt Especializado para Cadastro de Produtos (Nuvemshop)** (`Projetos/Cadastro-de-Produtos.txt`)  
   - Define o usuário como **Especialista em Cadastro de Produtos, SEO para E-commerce e Copywriter de Alta Conversão**, focado no nicho de dropshipping de artigos esportivos (camisas de times e tênis).  
   - **Objetivo:** gerar cadastros de produtos completos, prontos para copiar e colar na plataforma Nuvemshop, com foco em gerar desejo, quebrar objeções comuns (tempo de entrega, tamanho, qualidade) e otimizar SEO para buscas orgânicas.  
   - **Estrutura obrigatória de resposta:**  
     - Nome do produto (otimizado para conversão e SEO)  
     - Descrição do produto (formato HTML/texto) com gancho, história/conceito, detalhes técnicos e diferenciais (bullet points), tabela de medidas clara, instruções de lavagem/cuidados, garantia e suporte  
     - Tags (palavras-chave para busca interna e SEO)  
     - Campos de busca Google (título SEO ≤60 chars, meta description ≤160 chars, URL amigável)  
     - Sugestões de atributos/variantes (tamanho, personalização para camisas; tamanho/numeração, cor/modelo para tênis)  
   - **Regras de comportamento:** tom empolgante, focado na paixão pelo futebol/sneakers e exclusividade; nunca inventar tecnologias incompatíveis; manter textos limpos para colagem perfeita na Nuvemshop.

## Instruções de Uso
1. Para o prompt geral:  
   a. Abra o arquivo `Personalização de IA.txt`.  
   b. Copie todo o conteúdo.  
   c. Cole na conversa com seu modelo de linguagem preferido (ChatGPT, Gemini, Claude, etc.).  
2. Para o prompt de cadastro de produtos:  
   a. Acesse a subpasta `Projetos`.  
   b. Abra o arquivo `Cadastro-de-Produtos.txt`.  
   c. Copie todo o conteúdo.  
   d. Cole na conversa com seu modelo de linguagem preferido.  
3. A IA agora terá o contexto e as diretrizes para auxiliá-lo em estratégias de SEO, copywriting, branding, UI/UX, mídia social, vídeo, e na criação completa de cadastros de produtos para lojas virtuais, especialmente em plataformas como Nuvemshop, Shopify ou Yampi.  
4. Opcionalmente, você pode adaptar as seções para refletir seu nicho específico dentro de e-commerce ou dropshipping.
